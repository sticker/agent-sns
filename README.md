# Threads AI Agent System — アーキテクチャ

## 概要
6つのAIエージェントによるThreads自動運用システム。
ジャンル: AI・テック系 / プラットフォーム: Threads / 言語: TypeScript (Bun)

## セットアップ

```bash
cd threads-agents
bun install
cp .env.example .env
# .env にAPIキーを設定

# パイプライン実行（手動）
bun run pipeline

# cron投稿（ポスターのみ実行）
bun run post

# 緊急停止
bun run kill
```

## 設計の4原則

1. **エージェント分離** — 1エージェント = 1タスク
2. **ナレッジとロジックの分離** — knowledge/ を差し替えるだけでジャンル変更
3. **状態管理** — 全データをJSONで永続化。AIが文脈を保持
4. **安全装置** — 品質/類似度/投稿上限/間隔/KILL SWITCH

## 安全装置まとめ

| 項目 | 設定値 |
|------|--------|
| 品質スコア閾値 | 7.0 / 10.0 |
| 類似度閾値 | 0.85 |
| 1日最大投稿数 | 15件 |
| 最小投稿間隔 | 60分 |
| 連続エラー自動停止 | 3回 |
| KILL SWITCH | 有効 |
| パターン連続使用上限 | 2回 |
| テーマ連続使用上限 | 3回 |

## ジャンル追加方法

1. `knowledge/persona/` に新しいペルソナJSONを追加
2. `knowledge/themes/` に新しいテーマツリーを追加
3. `config/system.json` の `genre` を変更
4. パイプライン実行 → 新ジャンルで投稿開始
